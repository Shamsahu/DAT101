1. Where should you use constants, and where should you use variables? Can they all be constants?

    2. Constants should be used for values that should not change, while variables should be used for values that may change during the program. No, they cannot all be constants because som vales need to be updated.

  2. How do parentheses affect the arithmetic outcome of an expression?

    3. Parenteheses change the order in which parts of an arithmetic expression are calculated. The experession inide the parentheses is calculated first, which can change the final result.

  3. How do we limit floating-point numbers to a given number of decimals?

    4. We can limit a floating-point number to a specific number of decimal places by using the toFixed() method. For exaple toFixed(2) shows the number with two decimal places.

  4. How can we compare two floating-point values to see if they are equal (is 12.199999 the same as 12.2)?

    5. We should compare floating-point numbers using a small tolerance instead of checking exact equality. For example if the difference between the two numbers is very small we can treat them as equal.

  5. What do comparison operators return, and how can we check if they are FALSE or TRUE?

    6. Comparison operators retuen Boolean values (TRUE or FALSE). we can check the result directly in an if statement or compare the value with true or false.

  6. How does the Math.random() function work, and what can it be used for?

    7. Math.random()generates a random decimal number from 0 up to, but not including, 1. It can be used to create random values, for example a random number within a specific range.

  7. What is modulus (%), and when do we need this operator in mathematical operations?

    8. The modulus operator (&) returns the remainder after sivisjon. It is useful when we need to find what is left over after dividing numbers for example finding the remaining days after calculating full weeks.
