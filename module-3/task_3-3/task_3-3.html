1. What is the difference between invoking and creating a function?

    2. Creating a function means writing the code and defining what the function should do. Invoking a function means calling it to run the code inside it.

  2. Explain the syntax regarding semicolons and code blocks.

    3. Semicolons are used to end statements in JavaScript. Code blocks use curly brackets {} to group statements together.

  3. What happens when we try to store values from a function when it doesn't return any?

    4. If a function does not return a value, the variable that stores the result will be undefined.

  4. How do we separate parameters from each other when creating a function?

    5. We separate parameters by using commas inside the parentheses of the function.

  5. Explain how parameter names are related during the invocation and creation of a function.

    6. When creating a function, we give names to its parameters. When invoking the function, we pass arguments in the same order. The argument names do not need to match the parameter names.

  6. Explain why a parameter is undefined when a function call is missing a parameter.

    7. When we call a function without providing an argument, JavaScript gives the corresponding parameter the value undefined, unless it has a default value.

  7. Explain what happens when we use recursive functions.

    8. A recursive function is a function that calls itself. It repeats the process until a stopping condition is reached. Without a stopping condition, it can cause an error.
